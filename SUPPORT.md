# Support & Community

This project runs on community help, not funding.

## How you can help

- **Test it** — different OS (Windows/Linux), different providers (Ollama, OpenAI, Agnes AI, Google), different project types.
- **Report bugs** — see [CONTRIBUTING.md](CONTRIBUTING.md) and the [bug report template](.github/ISSUE_TEMPLATE/bug_report.md).
- **Suggest features** — via the [feature request template](.github/ISSUE_TEMPLATE/feature_request.md).
- **Contribute code** — PRs welcome, see [CONTRIBUTING.md](CONTRIBUTING.md).

## No financial support needed

This project does not seek or accept donations, sponsorship, or paid support. The only currency it runs on is bug reports, testing, and pull requests.

## Your data, your responsibility

Everything runs locally with your own API keys. Any code, files, or data you load into it is entirely your responsibility — see [DISCLAIMER.md](DISCLAIMER.md). No data is sent to the maintainer.

## Getting help

Open an issue for bugs or questions. There is no private support channel.
